# 환경 설정

이 프로젝트는 로컬과 운영 환경만 구분합니다.

## 로컬 환경

### Frontend

1. `my-news-front/.env.local.example`을 참고해 `my-news-front/.env.local`을 작성합니다.
2. 기본값:

```env
NEXT_PUBLIC_API_BASE_URL=/api
BACKEND_BASE_URL=http://localhost:3000
```

3. 실행:

```bash
npm run dev:front
```

### Backend

1. `my-news-back/.env.local.example`을 참고해 `my-news-back/.env`를 작성합니다.
2. 필수값:

```env
NODE_ENV=local
PORT=3000
CORS_ORIGIN=http://localhost:3001
ENABLE_SWAGGER=true
ENABLE_NEWS_SCHEDULE=true
ENABLE_STARTUP_NEWS_FETCH=true
DATABASE_URL=postgresql://...
NAVER_CLIENT_ID=...
NAVER_CLIENT_SECRET=...
```

3. 실행:

```bash
npm run dev:back
```

## 운영 환경

### Frontend

1. `my-news-front/.env.production.example`을 기준으로 `my-news-front/.env.production`을 작성합니다.
2. `BACKEND_BASE_URL`은 실제 백엔드 API 도메인으로 설정합니다.

### Backend

1. `my-news-back/.env.production.example`을 기준으로 `my-news-back/.env.production`을 작성합니다.
2. 권장값:

```env
NODE_ENV=production
ENABLE_SWAGGER=false
ENABLE_STARTUP_NEWS_FETCH=false
ENABLE_NEWS_SCHEDULE=true
CORS_ORIGIN=https://your-front-domain.com
```

## RAG 환경

뉴스 의미 검색은 Ollama embedding 모델과 Neon `pgvector`를 사용합니다.

```env
ENABLE_RAG_INDEXING=false
RAG_EMBEDDING_PROVIDER=ollama
RAG_EMBEDDING_MODEL=nomic-embed-text
RAG_CHUNK_SIZE=1200
RAG_CHUNK_OVERLAP=160
OLLAMA_BASE_URL=http://localhost:11434
```

로컬에서 사용할 때:

```bash
ollama pull nomic-embed-text
```

```env
ENABLE_RAG_INDEXING=true
```

자세한 내용은 `docs/RAG-벡터-파이프라인.md`를 참고합니다.

## 로컬 LLM 요약 환경

뉴스 상세 화면의 AI 요약 기능은 Ollama 생성 모델을 사용합니다.

```env
ENABLE_LOCAL_LLM_SUMMARY=false
OLLAMA_BASE_URL=http://localhost:11434
LOCAL_LLM_MODEL=qwen3:1.7b
LOCAL_LLM_SUMMARY_MAX_INPUT=6000
```

로컬에서 사용할 때:

```bash
ollama pull qwen3:1.7b
```

```env
ENABLE_LOCAL_LLM_SUMMARY=true
```

자세한 내용은 `docs/로컬-LLM-뉴스-요약.md`를 참고합니다.

## 운영 주의

Render 무료 운영 환경에서는 Ollama 직접 실행을 권장하지 않습니다. 운영 판단은 `docs/RAG-로컬-LLM-운영-검토.md`를 참고합니다.

## 실행 명령

npm run build
